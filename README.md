# Электронный журнал школы

Настольное приложение на Python (Tkinter + SQLite) для учёта учеников и оценок.

## Возможности
- вход по логину и паролю (пароли хранятся как PBKDF2-хеш с солью), смена пароля;
- роли: администратор (всё, управление пользователями) и учитель (только свои классы);
- классы (с удалением), ученики (изменение ФИО, перевод в другой класс), поиск по всем классам;
- оценки 1–10 с выбором даты (календарь) и удалением, средний балл и средний балл по предметам;
- учебные четверти 2026/2027 (по приказу Минпросвещения РК): оценка за четверть и итог за год, экспорт итогов в CSV;
- посещаемость и подсчёт пропусков;
- рейтинг класса, средний балл класса по предметам, экспорт отчёта в CSV (Excel);
- добавление и удаление предметов;
- HTTP API (JSON) для обмена данными с внешними сервисами;
- модульные тесты (unittest).

## Запуск
    python main.py            # вход: admin / admin123 (смените пароль!)
    python -m unittest discover -v

## API (кнопка «Запустить API» на вкладке «Пользователи» или отдельно: python -m journal.api)
    GET /api/classes
    GET /api/students?class_id=1
    GET /api/students/<id>/grades
    GET /api/report/<class_id>
Пример клиента: `python -m journal.client`

## Структура
    journal/security.py  защита (хеширование паролей)
    journal/db.py        база данных, бизнес-логика
    journal/quarters.py  даты четвертей, округление оценок
    journal/theme.py     оформление, journal/widgets.py — календарь и таблицы
    journal/export.py    экспорт в CSV
    journal/api.py       HTTP API
    journal/client.py    клиент API
    journal/app.py       интерфейс
    tests/               модульные тесты
